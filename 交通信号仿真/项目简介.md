# 自适应路口交通信号配时仿真系统 —— 项目简介

## 一句话概述

基于 Python 实现的十字路口**微观交通仿真平台**，对车辆、信号灯、路口进行面向对象建模，实现固定配时、基于排队反馈的自适应配时、Webster 最优周期优化三种信号控制算法，并在均衡 / 不均衡 / 潮汐时变三组车流场景下量化对比通行效率，得出「需求稳定用 Webster、需求波动用自适应」的结论。

---

## 一、项目背景与目标

真实道路上试错不同信号灯方案的代价极高。本项目通过计算机仿真，低成本模拟路口车流运行，对三种信号控制策略进行公平对比（同一路口、同一车流、同一随机种子、同一最短/最长绿灯约束），用**平均等待时间、P95 分位等待、最大排队长度、吞吐量、服务率**等交通工程指标，量化评估不同方案在不同车流场景下的通行能力，为信号控制策略选型提供直观依据。

---

## 二、核心实现

1. **微观交通仿真引擎**：三车道十字路口，含左转/直行/右转转向车流（贝塞尔转弯轨迹）；车辆按泊松过程到达；采用 **IDM（Intelligent Driver Model）跟驰模型**描述加减速与安全车距，替代「红灯停、绿灯走」的二值逻辑，仿真更真实、不穿模。
2. **三种信号控制算法**（共用同一相位状态机，公平对比）：
   - **固定配时**：各相位绿灯时长恒定，对应传统定时红绿灯；
   - **自适应配时**：实时感应排队与车流，采用标准 **gap-out 控制**——车流持续则逐秒延长绿灯（至上限），车流出现空档则立即切换，并内置最长等待公平性兜底；
   - **Webster 优化**：按 `C0=(1.5L+5)/(1-Y)` 离线计算最优周期与绿信比。
3. **多路口网格 + 绿波协调**：将单路口扩展为 2×2、3×3 等矩形路网，相邻路口按「路段长度 ÷ 车速」设置**相位差**，使主干道车流沿绿波方向连续通过；与「独立配时」对比，量化绿波协调在单向潮汐主干道上的通行改善。
4. **交通评价指标**：平均等待、P95 分位等待、最大/平均排队、吞吐量、服务率（v/c 比），参照 HCM 通行能力评价口径。
5. **数据持久化**：SQLite（默认零配置）与 MySQL（环境变量切换）双后端，保存每次仿真的参数与指标，支持历史对比。
6. **可视化**：Pygame 桌面端实时渲染路口、车辆、信号灯与指标面板；Flask Web 控制台可在浏览器中交互；**单文件 HTML 报告**（内嵌 Canvas 实时动画、信号灯、指标对比表与图表，浏览器直接打开）；matplotlib 自动导出对比图表。

## 三、实验结论（统计期 1800s，实测数据）

以固定配时为基准的平均等待时间改善（负值 = 更好）：

| 场景 | 自适应配时 | Webster 优化 |
|------|-----------|-------------|
| 均衡车流（300~900 辆/时） | -39% ~ +12% | -43% ~ -2% |
| 主次不均衡（南北主干 / 东西次干） | **-33% ~ -47%** | **-41% ~ -47%** |
| 潮汐时变车流 | **-32.8%** | **+19.8%（失配）** |

**三点结论：**

1. 需求**已知且稳定**时，**Webster 离线优化最优**（预先算好最优绿信比）；
2. 需求**不均衡**（主次干道）时，自适应与 Webster 都能把绿灯让给繁忙方向，平均等待比固定配时降低约 40%；
3. 需求**随时间波动**（潮汐车流）时，**只有自适应配时有效**——Webster 按平均需求离线计算反而失配（+19.8%），固定配时无能为力。

**多路口绿波协调（方向偏置 = 单向潮汐主干道，统计期 360s）：**

| 网格 | 独立配时·等待 | 绿波协调·等待 | 改善 | 独立·最大排队 | 协调·最大排队 |
|------|-------------|-------------|------|--------------|--------------|
| 2×2 | 69.79s | 52.53s | **-24.7%** | 241 | 221 |
| 3×3 | 72.36s | 56.74s | **-21.6%** | 444 | 317 |

> 绿波协调的价值在于**方向性**：单向主干道越明显，改善越大；双向均衡车流下固定绿波优化一个方向会牺牲另一方向，此时更适合自适应配时或 Webster 优化。

## 四、技术栈

Python · Pygame（渲染）· NumPy（统计）· matplotlib（图表）· SQLite / PyMySQL（存储）· Flask（Web）· HTML/Canvas（报告）· IDM 跟驰模型 · Webster 信号配时公式 · 绿波协调相位差 · 面向对象设计 · 离散时间仿真

---

## 五、项目价值

- 用低成本仿真替代高成本的现场试错，量化不同信号策略的通行效率；
- 覆盖**单路口算法对比**与**多路口绿波协调**两个层面，从微观到路网级；
- 串联**面向对象编程、离散事件仿真、控制算法设计、数据库开发、数据可视化**等多方面能力，体现后端、算法与工程综合开发素养；
- 模块化架构（配置 / 模型 / 策略 / 引擎 / 存储 / 指标解耦），易扩展至更多路口、转向保护相位、公交优先等场景，适合放到 GitHub 持续维护。

## 简历精简版

> 十字路口交通信号微观仿真系统，基于 Python + Pygame 开发，采用面向对象方法对车辆、信号灯、路口建模，以 IDM 跟驰模型与离散帧循环实现微观交通仿真。实现固定配时、基于排队反馈的 gap-out 自适应配时、Webster 最优周期优化三种控制算法，并扩展至多路口网格与绿波协调（相位差联动）。采集平均等待、P95 分位等待、最大排队、吞吐量等交通指标。在均衡、主次不均衡、潮汐时变车流下实测对比：不均衡场景自适应与 Webster 较固定配时平均等待降低约 40%，潮汐场景仅自适应有效（-32.8%）；多路口单向潮汐主干道下绿波协调使平均等待降低 21.6%~24.7%，最大排队由 444 辆降至 317 辆。数据通过 SQLite/MySQL 持久化，可生成单文件 HTML 报告（含实时动画），模块化架构支持扩展。
